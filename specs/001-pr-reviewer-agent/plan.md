**Input**: User request — Observability overhaul: precise structured logging at every application layer; health-check endpoint log suppression (every 15 min not every request); full per-service visibility for ngrok, GitHub client, opencode subprocess, security scanner, queue, and CI gate.

**Note**: This plan is the spec-kit-core canonical synthesis of the V-Model artifact set, generated by `/speckit.v-model.plan`. It extends the base feature plan with the Observability Enhancement scope layered on top. See `.specify/templates/plan-template.md` for the execution workflow.

## Summary

The current PR Review Agent is operationally opaque: the console formatter emits unstructured plain-text lines while health-check probes fire every 10 s and saturate the log stream, and services like ngrok, GitHub API calls, opencode subprocess invocations, and security scanner runs produce no structured traces at all. This plan raises observability from **Low → High** across the full stack without changing any externally-visible behaviour.

Three concrete goals drive the work:

1. **Precise structured logging at every application layer** — every module (`webhook`, `filter`, `queue`, `runner`, `ci`, `github`, `security`, `state`, `config`) emits structured JSON log lines (`ts`, `level`, `service`, `event`, `run_id?`, `…context`) at the right granularity: lifecycle events, trigger decisions, I/O boundaries, state transitions, errors, and timing.
2. **Health-check log suppression** — `GET /healthz` fires every 10 s from Docker's healthcheck and saturates the log stream; a `HealthzFilter` on the uvicorn access logger suppresses individual lines and emits one summary line every **15 minutes** instead. The healthcheck interval in `compose.yaml` is also bumped to 5 m to reduce probe frequency at source.
3. **Full per-service visibility** — ngrok tunnel events (URL acquired, tunnel error, reconnect), GitHub API calls (method, URL, status, latency, retry attempt), opencode subprocess invocations (model, exit code, duration, result shape), and security scanner runs (tool, finding count, duration) each emit a dedicated structured log event.

**Project Type**: web-service / background daemon — unchanged

## Implementation Design

### A. `src/observability/configurator.py` (new file)

```python
# Implements: ARCH-013, SYS-014, REQ-015, REQ-NF-007
"""
LoggingConfigurator — structured JSON logging + HealthzFilter.

Sets up:
  - JsonFormatter: every log record → {"ts": <epoch_ms>, "level": "INFO",
      "service": "<logger_name>", "event": "<message>", **structured_kwargs}
      with secrets redacted by key name.
  - HealthzFilter: suppresses individual GET /healthz access-log lines;
      emits one summary line every HEALTHZ_LOG_INTERVAL_S = 900 s (15 min).
  - LoggingConfigurator.configure(): replaces _configure_logging() in app.py.
"""

HEALTHZ_LOG_INTERVAL_S = 900  # 15 minutes

_REDACT_KEYS = {"token", "secret", "password", "authorization", "auth", "key", "api_key", "apikey"}

class JsonFormatter(logging.Formatter):
    """Emit every log record as a single compact JSON line."""
    def format(self, record):
        obj = {
            "ts": int(record.created * 1000),
            "level": record.levelname,
            "service": record.name,
            "event": record.getMessage(),
        }
        # Merge structured kwargs passed via extra={}
        for k, v in record.__dict__.items():
            if k not in _LOG_RECORD_BUILTINS and not k.startswith("_"):
                obj[k] = "[REDACTED]" if k.lower() in _REDACT_KEYS else v
        return json.dumps(obj, ensure_ascii=False, default=str)

class HealthzFilter(logging.Filter):
    """
    Suppress uvicorn access-log lines for GET /healthz.
    Emit a single summary line every HEALTHZ_LOG_INTERVAL_S seconds.
    """
    def __init__(self, interval_s=HEALTHZ_LOG_INTERVAL_S):
        super().__init__()
        self._interval = interval_s
        self._last_ts = 0.0
        self._count = 0

    def filter(self, record):
        if "GET /healthz" in record.getMessage():
            self._count += 1
            now = time.monotonic()
            if now - self._last_ts >= self._interval:
                logging.getLogger("pr_reviewer.healthz").info(
                    "healthz_summary",
                    extra={"probes_since_last_summary": self._count}
                )
                self._last_ts = now
                self._count = 0
            return False  # suppress individual line
        return True

class LoggingConfigurator:
    @staticmethod
    def configure():
        """Wire JsonFormatter + HealthzFilter once at app boot."""
        root = logging.getLogger("pr_reviewer")
        if root.handlers:
            return
        root.setLevel(logging.INFO)
        h = logging.StreamHandler()
        h.setFormatter(JsonFormatter())
        root.addHandler(h)
        # Attach HealthzFilter to uvicorn.access
        ua = logging.getLogger("uvicorn.access")
        ua.addFilter(HealthzFilter())
        ua.handlers.clear()
        ua.addHandler(h)
        ua.propagate = False
```
